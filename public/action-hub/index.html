Host independently

All Action Hub code is in one standalone index.html file. It can run locally or on any static host, including GitHub Pages, Cloudflare Pages, Netlify, or your own web server. No paid API keys or ChatGPT services are required.

Privacy and limitations

Browser storage is not secure or synchronized across devices. Do not put personal secrets, confidential construction plans, or sensitive customer records here. Company research links open external searches. There is no live lead harvesting, login, shared database or automated outreach.
