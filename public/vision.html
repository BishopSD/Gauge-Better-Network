Our vision for California steel construction

A builder with a set of plans should be able to see who can supply the steel, who can install it, and what each estimate actually covers. Gauge Better Network aims to make those connections easier, starting in California and prioritizing U.S. suppliers.

How a project moves through the network

  1. The builder defines the job. Submit the location, plans, schedule, and materials or installation work needed. Project submission is free.
  2. GBN reviews the scope. The operator follows up on missing details and identifies suppliers and independent installation teams suited to the project.
  3. Partners prepare estimates. Suppliers price materials. Installation teams quote labor. Each can identify exclusions, delivery assumptions, and timing.
  4. The builder compares options. Review comparable scopes and lead times. Any fee for access to approved estimates should be visible before checkout. The builder chooses whom to work with.

What we want to improve first

Our first testing priorities are whether a builder can describe a job on a phone, a supplier can identify missing specifications, and a builder can tell which estimate includes delivery. Feedback on a confusing step helps us decide what to improve next.

How developers can help

Start with one issue, describe the step that needs improvement, and propose a focused change in a GitHub pull request. Include how you tested it so the owner can review the change before it reaches visitors.
